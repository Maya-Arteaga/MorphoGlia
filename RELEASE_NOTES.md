# MorphoGlia 2.0.0

MorphoGlia 2.0.0 is a major redesign of the published MorphoGlia software.

## Highlights
- Shared GUI/script backend.
- Locked multi-platform Pixi environment.
- Raw, Binary, and Labels input modes.
- MG1–MG4 Raw preprocessing recipes.
- Explicit 2D/3D biological image geometry.
- Stage-aware recomputation, prerequisite reuse, and resume/checkpoint logic.
- Instance postprocessing for small objects, tubular fragments, and large objects.
- Unified morphometrics and QC.
- PCA-based latent-space analysis and multiresolution morphology-state estimation.
- Supported researcher-selectable morphology-state resolutions.
- Prototype, mapping, composition, profile, temporal, and morphospace outputs.
- Configurable morphology-state palettes and figure DPI.
- Category-specific plot directories.
- Technical Record provenance.

Spatial Analysis remains intentionally disabled in the public 2.0.0 interface.
The historical `fluorescence_v1` Raw preprocessing name remains accepted as an
alias of MG1 for compatibility.
